PICKLEBALL EDITION

入哪个球场
就说哪种球话

匹克球场上的每一句喊话、每一个术语——中英对照，一查就懂。

🎯 记住这 10 句

📖 实战对话流
你（发球前）："Zero, zero, two!" → 发球 → 对方："Nice serve!"
对方球出底线：你 "Out!" → 对方："You sure?" → 你："Yes, out by this much!"
外来球滚入：任何人 "Ball on!" → 所有人停 → 重打该分
比赛结束："Good game!" → 网前碰拍 → "Same time next week?"

🗣️呼报 Calls场上喊出来的话——不懂就社死
Ball on!
球入侵！立即停
外来球滚入本方场地时大喊，所有人停下，该分重打。安全永远比分值大。
Out!
出界
球落在界外。须在球落地后立刻喊出＋手势；提前喊不产生死球效果。
Side out
换发
发球方输掉本回合，发球权交给对方。双打须两名球员都发完才换。开局例外：首个发球方只有 1 人发——0-0-2 的「2」即计作第二发球员。
Score / Calling the score
喊分
发球前须完整喊分。双打三段「0-0-2」＝发方分-接方分-第几发球员。
Fault
违例/失误
任何违反规则的行为。裁判喊出即死球。
Kitchen violation
厨房违例
非截击区内凌空击球（含凌空时踩线）＝ fault，判失该回合。
Mine! / Yours!
我的！/ 你的！
双打搭档间喊位。规则保护冲搭档的喊话不构成干扰——但冲着对手喊可判 distraction。
In / Ball in
界内
球落在有效区域内。自己半场自己判，存疑判界内。
Short
发球太短
发球未过厨房线，判 fault。
Long
发球出底线
发球越过底线，判 fault。非上旋高速平球大半出底线——接发方可喊「让它飞」。
Let it go /liːt ɡoʊ/
让它飞！
判断来球将出底线时喊给搭档：别碰。判断错、球落界内＝白送对手一分。
Bounce it! /baʊns/
让它弹！
提醒搭档别凌空、等球落地再打——两跳规则限定下抢这一拍就是 fault。
Switch!
换位！
喊搭档交换左右半区——中路球打完、被挑高球打身后、或抢网之后，一声 switch 完成换防。
Nice shot / Good ball
好球！
只对好球说——对失误叫好是喝倒彩。
Hold! / Wait!
等一下！
死球时请求暂停。非正式口令但球友圈通用。
Dead ball
死球
回合结束、球失去活性。只有死球后才能喊分、叫暂停、纠正站位。
Rally /ˈræli/
回合/对拉
从发球到死球的一个完整往返。多拍打完一句 great rally! 是给双方的最高致敬。
Replay
重打该分
因外来球（Ball on!）、意外干扰中断的回合重打，比分不变。
Foot fault
脚误
发球击球瞬间脚触底线/场内、或站到边线延长线外——判 fault。口语里厨房线违例也叫 foot fault，正式名称是 NVZ violation。
Wrong server / Wrong receiver
发错人/接错人
不该发的人发了球，或非接发球员接了球。
No let
无重发
匹克球没有 let——发球擦网后只要落对角发球区就是好球，照打不误。从网球/乒乓转来的球友最容易习惯性喊 let。
Distraction
干扰（判罚）
对手在你击球前后故意喊叫、挥手、制造声响，可判其 fault。Mine/Yours 只许冲搭档喊。
Hindrance / Hinder
阻碍（判重打）
场外意外因素打断回合——他场球滚入、观众穿越——判 replay。与 distraction 的区别：一个故意，一个意外。
Time violation
拖延时间违例
10 秒规则：喊完分后须在 10 秒内发球。先口头警告，再犯判 fault。
Verbal / Technical warning
口头/技术警告
对脏话、吼叫、摔拍等违反体育道德行为的警告阶梯：先 verbal，再 technical（判对方得 1 分）。
Technical foul / Ejection
技术犯规/取消资格
行为恶劣（辱骂裁判、斗殴）可直接 ejection 驱逐出场。
🏓动作 Actions技术动作的英文名
Dink /dɪŋk/
轻放短球（叮球）
网前厨房线附近的慢速软球，匹克球的标志性技术。中文圈也叫「叮」。
Drop / Third shot drop
第三拍轻放
从底线打出慢速高弧线落入对方厨房区，用来买时间冲上网前。匹克球战术基石。
Drive
抽球/平抽
快速低平的进攻球。低于网口的平抽极易出界——须靠上旋把球托过网再下坠。
Volley /ˈvɑːli/
截击/凌空
球落地前的击球。厨房区内禁止截击。
Serve（Volley serve / Drop serve）
发球（凌空式/落地式）
Volley serve：球离手后凌空击出——触球点低于肚脐、拍头低于手腕、上扬弧线。Drop serve：球落地弹起后再击。均须对角发入发球区，深度比速度重要。
Return of serve
接发球
金律「接发必深」——深球钉住发球方在底线，你趁球在飞抢到厨房线。
Speed up
加速/提速
在网前对拉中突然加速进攻。只有球高于网时才有效——低于网加速极易出界。
Reset
重置/卸力
被猛攻时松握拍吸收动能，把球软软放回对方厨房——化解攻势的核心技术。
Block
挡球
零引拍的被动防守。接重杀的核心。
Punch volley
弹击截击
网前不引拍、用肩膀短促前送的截击——手速战的主力武器。
Roll shot
卷绕球
拍面从低处往上卷绕的中速上旋球——从膝盖高度直接卷起进攻，比 speed up 稳、比 dink 狠。
Half volley
半截击
球刚弹地还在上升期就击球——时机极难。要诀：短动作＋死手腕。
Groundstroke
落地球
球落地一次后的常规击球，分正手 forehand／反手 backhand。
Overhead / Smash
高压球/扣杀
「往外打，不是往下打」——匹克球高压打深不打狠。
Lob /lɑːb/
挑高球
把球高高挑过对手头顶。匹克球中是高风险武器。
Attacking dink
进攻型叮球
叮球突然加力加速——把软球武器化。
Dead dink
死叮
软绵绵、无角度的叮球——等于送对手免费加速。叮球要活：变线、加力、打脚。
Counter / Counterattack
反击
接住对手的 speed up 并加速压回——网前手速战真正的得分手段。
Put-away
终结球
结束回合的最后一击。会制造 put-away 机会比会抡更重要。
Topspin / Slice
上旋 / 切削
上旋让球过网后急坠；切削让球低平慢滑——变节奏的暗器。
Erne /ˈɜːrni/
绕厨截击
绕过厨房区、在边线外侧完成的截击——可地面绕过或空中凌空。以 Erne Perry 命名。
Bert /bɜːrt/
反手厄尼
在搭档那半边绕过厨房区、用反手打的凌空截击。《芝麻街》Ernie & Bert 的梗。
ATP (Around The Post)
绕柱击球
球从网柱外侧飞过，完全合法——规则只要求过网或过柱。
Chicken Wing
鸡翅膀（死穴）
持拍侧肩膀/腋下——正手无法折叠到胸前防守的位置。加速攻击的首选目标。
Scorpion /ˈskɔːrpiən/
蝎子尾击球
追身球砸到脚边时拍头贴地、手腕像蝎子尾从下往上弹卷的应急防守。帅但费腕。
Transition shots /trænˈsɪʒən/
过渡区击球
在死区边打 reset／drop 边往网前走——穿越死区的生存技能。
Third shot drive
第三拍抽球
第三拍不打 drop 直接平抽——对手挡高了搭档就扑杀。风险与机会同在。
Drop volley
截击放短
厨房线上凌空接软球直接轻放进对方厨房——逼对手拔脚后撤。
📍场地 Court
Kitchen / Non-Volley Zone (NVZ)
厨房/非截击区
网前 7 英尺区域，禁止凌空击球。名字借自沙狐球罚分区。
Kitchen line
厨房线
非截击区边界线。线本身属于厨房——凌空时踩线＝踩厨房。
Baseline
底线
发球时脚不得踩线。
Sideline
边线
发球站位不得踩边线延长线外。
Centerline
中线
划分左右发球区的线。
Service court
发球区
发球落点有效区域（对角），厨房线上的发球为 short。
No-man's land / Transition zone
死区（＝过渡区）
厨房线与底线之间——停留此处最危险，但冲网必须穿越它。
Serving area
发球站位区
底线后、两延长线之间的区域——发球瞬间双脚须都在区内。
Right (Even) / Left (Odd) court
右偶数场/左奇数场
己方偶数分右区发、奇数分左区发。0-0-2 从右手位开始。
Cross-court
对角区
网对面的斜对角区域。发球必须对角。
Imaginary extension
假想延长线
中线与边线向底线外的虚拟延长线——发球站位与 ATP 判罚的依据。
Permanent object
固定物
网柱、围栏、天花板等。球在落地前碰到＝fault。
Net post
网柱
比网中心略高。球碰柱＝fault——除非你打出 ATP。
🏸装备 Equipment
Paddle（不是 Racket）
球拍（匹克球专用）
实心无弦叫 paddle。说 racket 暴露新手身份。
Continental grip
大陆式握拍
主流教法推荐——像握榔头，全场一套不换握。手腕锁死的前提。
Grip size
握把粗细
4～4.5 英寸。宁选偏细（可缠 overgrip 加粗）。
Paddle face / Core
拍面/拍芯
碳纤维或玻璃纤维面；16mm 厚芯＝控制型。
Holes
球洞数
26-40 为典型值：室外常见 40 小洞，室内常见 26 大洞。
Sweet spot
甜区
拍面力量与手感最好的中心区域。厚芯拍甜区更大。
Weight & Swingweight
重量与挥重
7.5-8.5 盎司常见；挥重才是打感关键。
Edge guard
护边
拍框外圈保护条。Edgeless 无边拍甜区完整但更娇贵。
Grit / Face texture
拍面砂感
碳纤表面粗糙涂层，抓球造旋。砂感会随使用磨损。
Paddle shape
拍形
标准型全能；加长型力臂长；宽面型容错高、新手友好。
Lead tape
铅条配重
几克就能改变手感。改拍有风险，先试 demo。
Overgrip
外缠手胶
消耗品常换常新，也是加粗半号的零成本方式。
PBCoR
恢复系数测试
2024 年起的「蹦床效应」检测——超标拍被下架。读作 P-B-core。
USAP approved
官方认证
正式比赛须用认证拍与球。认证清单官网可查。
DUPR /ˈduːpər/
匹克球「段位」
约 2.0 新手～8.0 顶级。约球、报赛、分队全看它。读作 dupe-r。
♟️战术 Tactics
Stacking
堆叠站位
两人站同侧发球/接发，让正手覆盖中路。
Shading
同步横移
球往哪飞全队往哪移，封死空当。
Poach /poʊtʃ/
抢网
横移抢打搭档的球——抢完喊 switch 换位。
Shake and bake
抽放组合
一人抽球迫使对手挡高，搭档跟进扑杀。
Hands battle / Firefight
网前手速战
四人都在厨房线的快速对攻。
1-2 punch
组合拳
第一拍 70% 力做球，第二拍 100% 绝杀。
I-formation
I 字阵型
发球方沿中线排纵列，网前搭档蹲守虚晃。
Serving order
发球次序
每局开赛前固定，局中不可换。
First / Second server
第一/第二发球员
喊分第三位数字就是区分。
Stagger
错位站位
一人略缩后半步——防挑高球打身后。
Attackable ball
可攻球
高于网、速度慢、中前场的「送分球」。控制流目标：别给对手。
🔢计分 Scoring
Rally scoring
每球得分制
谁赢回合谁得分。MLP 等职业联盟已采用。
Traditional (Side-out) scoring
传统换发计分
只有发球方能得分。11 分制、净胜 2。
Game point
局点
发方再得一分即赢本局。
Match point
赛点
再得一分即赢整场。
Win by 2
净胜两分
10 平后须领先 2 分，不封顶。
Second serve
第二发
喊分第三位变成「2」。这口气再丢就交发球权。
Third number（0-0-2 的「2」）
第三位数字
双打喊分第三位＝发球员编号。开局 0-0-2 特例让发球数对半公平。
Time-out
暂停
常规每队每场 2 次 60 秒。比分胶着时打断对手手感也是战术。
Pickled
被腌了（零封）
0:11 被零封＝got pickled。
Golden pickle
金腌
11:0 且对手没摸到发球权。
Two-bounce rule
两跳规则
发球和接发都必须让球落地一次，之后才可凌空。
🥒圈内俚语 Slang球友黑话——听得懂才算自己人
OPA! /oʊˈpɑː/
冲啊！
网前加速对攻开始时的集体吼声——源自希腊语欢呼。
Banger
大力抽手
只会从底线猛抽不肯上网叮球的球友。半是描述半是吐槽。
Bodybag
追身装袋
直接冲对手身体砸的加速球。
Nasty Nelson
脏尼尔森
发球瞄准接发方的搭档——球碰接方任何人即 fault。够脏，友谊局慎用。
Falafel /fəˈlɑːfəl/
法拉费（哑火球）
打在拍框软绵绵飘落的失误球。名字来自中东小吃。
Flapjack
必弹球（煎饼）
两跳规则限定下「必须落地弹一次」的那两拍。
Pickleboat
腌菜船（起源梗）
匹克球名字来源：赛艇界 pickle boat＝东拼西凑组的船。
BADMINTON EDITION

羽毛球场上
这些词你必须听懂

🗣️呼报 Calls
Love all — play /lʌv/
零比零，开始
裁判开局宣告。Love=零分（源自法语蛋＝零）。
Fault /fɔːlt/
违例
发球超 1.15m 固定高度（旧称过腰，2018 年取代）、触网、连击等。
Service over
换发
发球方输回合交发球权。
In / Out
界内/出界
单打窄长场、双打宽短场——边线判断因单双而异。
Let /let/
重发球
双方同时违例、接发未准备好、外界干扰时重打。
Game point / Match point
局点/赛点
领先方再得 1 分赢本局/整场。
Interval /ˈɪntərvl/
技术暂停
每局先到 11 分休 60 秒；局间 2 分钟。
Change ends
换场

持球/拖带

🏸动作 Actions
Clear /klɪr/
高远球（后场球总称）
高弧线打到底线。分进攻平高与防守高远。
Smash
杀球/扣杀
从最高点向下全力击球——最帅但单打重杀是赌注。
Drop shot
吊球
后场轻吊到网前。与杀球动作一致，触球瞬间切托减速。
Drive
平抽球
快速平飞——双打中前场核心武器。平＝不给进攻权。
Net kill
扑球
把网前高于网带的球快速下压。击球点须在己方上空。
Lift
挑球
网前把球挑到后场。单打过渡；双打交出进攻权。
Block
接杀挡
零引拍防守——拍面迎前借力挡回。
Push /pʊʃ/
推球
网前快速平推到底线两角。
Tumble /ˈtʌmbl/
搓球（翻滚过网）
手指捻切球托侧面，让球翻滚过网即坠。
Slice /slaɪs/
劈球/切球
拍面斜切。劈吊带切减速；劈杀带侧旋更拐。
Hairpin /ˈherpɪn/
回搓/贴网球
U 形动作轨迹得名——球拍沿 U 形贴网往返，球过网即坠。
Whip /(h)wɪp/
鞭打发力
蹬地→转髋→转肩→倒拍→挥臂逐级加速。你是鞭柄拍是鞭梢。
Cross-court /ˈkrɔːs/
斜线球
打向对角——飞行最长、调动最大。
Straight / Down the line
直线球
沿边线直线下压或平推。重复直线最省力。
Attacking clear
平高球
弧平球速快——对手退不到位就丢主动。
Defensive clear
高远球
又高又远纯防守——被动时的重启键。
Interception
封网
双打网前举拍拦截平抽与半高球。
Deception /dɪˈsepʃn/
假动作
同一引拍打出不同球路——hold（停顿）与假挑真放。
High / Low / Flick / Drive serve
发球四种
高远发、低发、弹发（偷后场）、平射发。双打主打 Low＋Flick。
Return of serve
接发球
双打接发是回合最重要一拍：放网、推两腰、挑底线三选一。

后发球线（双打）
双打发球不得超过此线。单打以底线为界。

边线通道
单打边线与双打边线之间——单打出界、双打界内。

后发球线与底线之间——双打发球出此区＝出界；相持中界内。

底线 / 中线
中线划分左右发球区，发球必须发对角区。
Service court (even/odd)
发球区（右偶左奇）
偶数分右区发、奇数分左区发。0-0 从右区开始。
Net tape / Net cord
网带/网绳
擦网落区有效、继续打。
Singles / Doubles sideline
单双打边线
单窄长、双宽短。
Forecourt / Backcourt / Midcourt
前场/后场/中场
攻防转换的过渡区在中场。
🎒装备 Equipment
Racket /ˈrækɪt/
球拍（羽毛球叫 racket）
有弦床才叫 racket。匹克球实心拍叫 paddle。
Shuttlecock / Birdie /ˈʃʌtlkɑːk/
羽毛球
口语 birdie 或 shuttle。重约 5g，触拍仅 3-6ms。
String tension
拉线磅数
新手 20-24 磅——磅数跟发力走，不跟面子走。
String gauge /ɡeɪdʒ/
线径
细线弹性好不耐用；粗线耐打。
Pre-strung / Unstrung
带线拍/空拍
认真打选空拍——按自己的线型和磅数定制。
Head-heavy / Head-light / Even
头重/头轻/平衡
头重杀球重、头轻挥速快、平衡全面。
Shaft stiffness
中杆硬度
硬杆发力直接吃爆发力；软杆借力易打。
3U / 4U weight
拍重规格
3U=85-89g、4U=80-84g。双打多选 4U。
Grip size (G4/G5) / Overgrip
握柄尺寸/手胶
G5=80mm 亚洲常见。Overgrip 调粗细防滑吸汗。
Feather vs Nylon
鹅毛球 vs 尼龙球
鹅毛飞行最真耐打差；尼龙耐用但飞行衰减。
Shuttle speed (76/77/78)
球速
数字越小越慢。天热用 76、天冷用 78。
Court shoe
羽毛球鞋
非标记胶底＋横向支撑。穿跑鞋＝崴脚预订。
♟️战术 Tactics
Front-back rotation
前后轮转（进攻）
一人后杀一人网前封——双打进攻标准阵型。
Side-side defense
左右防守
被动挑高后两人分守半场。
Attack and defend rotation
攻防轮转
攻转守：杀球被挑后场；守转攻：挡网跟压。
Clear and drop game
拉吊
高远＋吊球反复调动——消耗中等机会一拍致命。
Four corners
四方球
长短结合打到四角——落点比力量重要。
Smash and rush
杀上网
杀球后跟进网前封挡网回球。
Fast and flat
平抽快挡
双打中前场平抽对挡——拼反应拼手速。
Half-smash
点杀/半杀
70% 力量保重心——先点杀压制再补刀终结。
Round the head
绕头顶
反手位高球不换反手、正手绕过头顶打。
Base position
回中（中心位）
每拍结束回中心——不回中＝送空当。
👟步法 Footwork
Split step /splɪt/
启动步
对手击球瞬间落地的小跳——落地即蹬出。
Chasse /ʃæˈseɪ/
并步
法语借词读「沙-SEI」。侧向滑步的基础。
Lunge /lʌndʒ/
蹬跨步
上网最后一步的大跨步——脚尖外展护膝。
Scissor kick
蹬转（剪刀步）
后场击球后前后脚交换落地顺势回中。
Forehand / Backhand grip（Bevel / Panhandle）
正反手握拍
正手如握手、反手拇指顶宽面。Bevel 管双打反手；Panhandle「平底锅」用于网前扑球。

2006 年起——赢球即得分，无论谁发。

🗣️呼报 Calls
Let
重发球
发球擦网落入对角台面＝let 重发，次数不限。
Point
得分
每球得分制，一局 11 分，10 平净胜 2。
Deuce /djuːs/
平分/加分
10 平后须净胜 2 分，无封顶。
Game point / Match point
局点/赛点
再得 1 分赢本局/整场。解说高频。
Game / Match
局/场
主流 Bo5（五局三胜），大赛后期 Bo7。
Service fault
发球违例
上抛≥16cm；掷球不得使球旋转（imparting spin）；不遮挡。
Edge ball
擦边球
球擦台面顶边＝有效。打出擦边要举手示意。
Net ball
擦网球
发球擦网落台面＝let 重发；对拉中擦网＝继续。
Obstruction / Volley /ˈvɒli/
拦击/阻挡
球未落本方台面就被碰到＝obstruction 判失分。乒乓球没有合法截击。
Double hit / Double bounce
连击/两跳
一侧连续击球两次或球在本方弹两次。
🏓动作 Actions
Loop /luːp/
弧圈球
强烈上旋攻击——先打后摩（撞透海绵再摩擦）。
Drive
快攻/抽球
快速平击低弧前冲——中国近台快攻招牌。
Push
推/搓
搓＝带下旋的推。寸劲沿球底部斜砍即停。
Block
挡球
零引拍防守——拍面迎前上升期顶住。防弧圈铁律：迎前不后缩。
Flip
挑打/拧
台内进攻——正手挑打、反手拧拉。台内短球不再只能摆短。
Smash
扣杀
机会球高压下杀——先打后摩。
Serve
发球
唯一完全自控的一拍。转与不转全靠触球部位。
Forehand / Backhand
正手/反手
解说缩写 FH/BH。两面都能打叫 two-wing。
Topspin / Backspin / Sidespin
上旋/下旋/侧旋
旋转三件套——乒乓球的灵魂变量。
Slow loop vs Fast loop
加转弧圈/前冲弧圈
加转＝旋转优先弧线高二跳急坠；前冲＝速度优先低平冲底线。
Counter drive
反带/快带
不引拍上升期借力快速回带——防转攻的衔接技术。
Pivot
侧身
侧身让位用正手打反手位——正手体系的灵魂。侧身＝赌对方不变线。
Banana flick
香蕉拧
反手拧的挥拍轨迹像香蕉——接发从控制变进攻的代表技术。
Lob
放高球
防守时高放逼对方失误——中远台的最后手段。
Chop-block
削挡
挡球＋削球混合——回球又短又沉带下旋。节奏破坏者的暗器。
Half-long serve
半出台发球
第二跳刚好出台——对手拉不实摆不稳。
Fast long serve
奔球
突然快速长球冲端线。对手贴台准备摆短时最致命。
Open up
上手/起板
把下旋相持转为第一板上旋进攻——谁先上手谁主动。
Chop
削球
防守型下旋——拍面仰从后上向前下切。
Twiddle /ˈtwɪdl/
转拍/倒板
回合中旋转球拍换面。已边缘化。
Punch /pʌntʃ/
弹击/快弹
反手小动作快速击球——近台反手对付半高球的快刀。

PICKLEBALL EDITION

入哪个球场
就说哪种球话

匹克球场上的每一句喊话、每一个术语——中英对照，一查就懂。

🗣️呼报 Calls场上喊出来的话——不懂就社死
Ball on!
球入侵！立即停
外来球滚入本方场地时大喊，所有人停下，该分重打。安全永远比分值大。
Ball in / In
界内
球落在有效区域内。自己半场自己判，存疑判界内。
Out!
出界
球落在界外。须在球落地后立刻喊出＋手势；提前喊不产生死球效果。
Side out
换发
发球方输掉本回合，发球权交给对方。双打须两人都发完才换。
Score / Calling the score
喊分
发球前须完整喊分。双打三段「0-0-2」＝发方分-接方分-第几发球员。
Fault
违例/失误
任何违反规则的行为。裁判喊出即死球。
Kitchen violation
厨房违例
在非截击区内凌空击球（含踩线），判失分。
Short
发球太短
发球未过厨房线，判 fault。俗称「发球落厨房」。
Long
发球出底线
发球越过底线，判 fault。注意：非上旋高速平球九成出底线，接发方可喊「让它飞」。
Hold! / Wait!
等一下！
死球时请求暂停（系鞋带、清异物）。非正式口令但球友圈通用。
Mine! / Yours!
我的！/ 你的！
双打搭档间喊位，防止撞拍。规则明确保护此喊话不构成干扰。
Nice shot / Good ball
好球！
对手或搭档打出好球时的赞美。只对好球说——对失误叫好是喝倒彩。
🏓动作 Actions技术动作的英文名
Dink
轻放短球（叮球）
网前厨房线附近的慢速软球，匹克球的标志性技术。中文圈也叫「叮」。
Drop / Third shot drop
第三拍轻放
从底线打出慢速高弧线落入对方厨房区，用来买时间冲上网前。匹克球战术基石。
Drive
抽球/平抽
快速低平的进攻球。匹克球中低于网高抽球必出界（除非加极强上旋）。
Volley
截击/凌空
球落地前的击球。厨房区内禁止截击。
Reset
重置/卸力
被猛攻时松握拍吸收动能，把球软软放回对方厨房——化解攻势的核心技术。
Speed up
加速/提速
在网前对拉中突然加速进攻。只有球高于网时才有效——低于网加速必出界。
Block
挡球
零引拍的被动防守，靠拍面角度把球挡回去。接重杀的核心。
Lob
挑高球
把球高高挑过对手头顶。匹克球中是高风险武器——无搭档补救。
Overhead / Smash
高压球/扣杀
头顶上方的高球下压。匹克球高压打深不打狠——「往外打，不是往下打」。
Serve
发球
必须低手发球（低于腰），对角发入发球区。深度比速度重要。
Return of serve
接发球
接发方的第一拍。金律「接发必深」——深球钉住发球方在底线。
Erne
飞跃截击
从厨房线外侧起跳、飞跃厨房区在空中截击。以 Erne Perry 命名。合法但罕见。
ATP (Around The Post)
绕柱击球
球从网柱外侧飞过（不经过网上方），完全合法——规则只要求过网或过柱。
Chicken Wing
鸡翅膀（死穴）
对手持拍侧肩膀/腋下区域——正手无法折叠到胸前防守的位置。加速攻击的首选目标。
📍场地 Court球场各区域和线的叫法
Kitchen / Non-Volley Zone (NVZ)
厨房/非截击区
网前 7 英尺（2.13m）区域，禁止凌空击球。名字借自沙狐球的罚分区。
Kitchen line
厨房线
非截击区的边界线。线本身属于厨房——凌空时踩线＝踩厨房。
Baseline
底线
场地最远的边界线。发球时脚不得踩线（线属场地内）。
Sideline
边线
场地两侧的边界线。发球站位时不得踩边线延长线外侧。
Centerline
中线
从厨房线到底线、划分左右发球区的线。
No-man's land
死区/真空带
厨房线与底线之间的过渡区域。停留此处最危险——既不能截击也够不到底线球。
Service court
发球区
发球的落点有效区域（对角），含边线到底线，不含厨房区（厨房线上的发球为 out）。
🏸装备 Equipment买装备前必懂的词
Paddle（不是 Racket）
球拍（匹克球专用词）
匹克球的拍子叫 paddle 不叫 racket——实心无弦。说 racket 会暴露新手身份。
Paddle face / Core
拍面 / 拍芯
拍面材质（碳纤维/玻璃纤维）；拍芯厚度影响控制与力量（16mm 厚芯=控制型）。
Holes（球的洞）
球洞数
规则规定 26-40 个洞：室外球 40 个小洞（重硬抗风），室内球 26 个大洞（轻慢好控）。
PBCoR
拍/球恢复系数测试
2024 年起的「蹦床效应」检测——超标球拍被下架（如 JOOLA Gen3 全系列）。
Continental grip
大陆式握拍
匹克球标准握法——像握榔头，全场一套不换握。手腕锁死的技术前提。
♟️战术 Tactics战术术语
Stacking
堆叠站位
双打中两人站同侧发球/接发，让正手覆盖中路。匹克球特有的阵型策略。
Shading
同步横移
两人像被隐形棍连着——球往哪飞全队往哪移，封死空当。
Shake and bake
抽放组合
一人抽球迫使对手挡高，搭档跟进扑杀。匹克球经典配合。
Hands battle / Firefight
网前手速战
双打四人都在厨房线的快速对攻。比的是反应速度和短挥回位。
1-2 punch
组合拳
第一拍 70% 力打对手右髋做球，第二拍 100% 绝杀。单拍很难打死人。
Two-bounce rule
两跳规则
发球和接发都必须让球落地一次，之后才可凌空。规则层面的「开局别抢」。
BADMINTON EDITION

羽毛球场上
这些词你必须听懂

🗣️呼报 Calls
Love
零分
源自法语 l'œuf（蛋＝零）。开局「Love all」＝双方零比零。
Let
重发球
发球时双方同时违例、或有干扰时判重发。羽毛球有 let，匹克球没有。
Fault
违例
任何违反规则的行为：发球过腰、触网、连击、过网击球等。
Setting / Extra points
加分/延长赛
20 平后需净胜 2 分（封顶 30）。2027 起 14 平加分（新 3×15 制）。
Service over
换发
发球方失分，发球权交给对方。
In / Out / Line call
界内 / 界外
羽毛球单打窄长场、双打宽短场——边线判断因单双打而异。
🏓动作 Actions
Clear
高远球
把球打到对方底线的高弧线球。单打的基石技术——用高度换时间回中。
Drop shot
吊球/短球
从后场轻吊到对方网前。与杀球动作一致，触球瞬间减速——靠摩擦减速不靠放慢挥拍。
Smash
杀球/扣杀
从高处向下全力击球。羽毛球最帅的动作——但单打中重杀是赌注（重心钉死自己）。
Drive
平抽球
快速平飞的进攻球，双打平抽挡的核心武器。平＝不给对方高度＝不给进攻权。
Net shot / Net kill
网前球 / 扑球
网前搓/放短球（Net shot）；在网上方把球往下压（Net kill/扑球）。
Lift
挑球/挑高球
从网前把球高高挑到对方后场。单打中的过渡——双打中是交出进攻权。
Block
挡球/挡网
接杀时的零引拍防守——靠拍面迎前＋手指瞬间锁死借力弹回。
Tumble / Spin net shot
搓球（翻滚过网）
手指捻动拍柄切削球托侧面，让球翻滚过网即坠。羽毛球独有的精细技术。
Slice
劈球/切球
拍面斜切球托，制造侧旋或减速。劈杀（slice smash）＝杀球带切，更刁钻。
Hairpin
网前搓球（搓对角）
贴网来回搓球的技术——像梳头发一样贴近网带轻轻摩擦。
Whip / whipping action
鞭打发力
蹬地→转髋→转肩→倒拍→挥臂的逐级加速——你是鞭柄，拍是鞭梢。
📍场地 Court
Short service line
前发球线
发球必须过此线（距网 1.98m）。
Long service line (doubles)
双打后发球线
双打发球不得超过此线（距底线 0.76m）。单打发球可到最外底线。
Tramlines / Side alley
边线通道/双打边线
单打边线与双打边线之间的窄条区域。单打出界、双打界内。
Back tramline
后通道
双打后发球线与最外底线之间的区域。双打发球出界（落此区），相持时界内。
Forecourt / Backcourt / Midcourt
前场 / 后场 / 中场
网前到前发球线=前场；后发球线到底线=后场；中间=中场（也是 transition 过渡区）。
🏸装备 Equipment
Racket（不是 Paddle）
球拍（羽毛球用 Racket）
羽毛球拍有弦床，叫 racket/racquet。匹克球的实心拍才叫 paddle。
Shuttlecock / Birdie / Shuttle
羽毛球/球
正式名称 shuttlecock，口语 birdie 或 shuttle。重约 5g，触球仅 3-6ms。
String tension (lbs)
拉线磅数
磅数越高线床越硬、容错越低。新手 20-24 磅——磅数跟发力水平走，不跟面子走。
Shoe / Court shoe
球鞋/场地鞋
羽毛球鞋底薄硬、防滑侧移。穿跑鞋打羽毛球容易崴脚。
♟️战术 Tactics
Front-back rotation
前后轮转（进攻阵型）
一人后场杀球一人网前封网——羽毛球双打进攻标准阵型。
Side-side defense
左右防守（防守阵型）
被动挑高后两人分守半场——防守标准阵型。攻转守/守转攻即轮转。
Third shot
第三拍
羽毛球术语中也用——接发后的第三拍是攻防转换的关键节点。
Half-smash
点杀/半杀
用 70% 力量的杀球——保持重心、连续压制。单打中比重杀更常用。
Round the head
绕头顶/头顶球
反手位的高球不用反手打，而是用正手绕过头顶——比反手更有攻击力。
TABLE TENNIS EDITION

乒乓球这些词
英文原来这么说

🗣️呼报 Calls
Let
重发球
发球擦网落在对角正确区域＝重发。乒乓球有 let（匹克球没有）。
Point
得分
每球得分制（rally point），11 分制（2027 年讨论 3×15 制）。
Deuce
平分/加分
10 平后需净胜 2 分。乒乓球 11 分制、羽毛球 21 分制都有 deuce。
Game / Match
局 / 场
Game=一局（先到 11 分）；Match=整场（三局两胜或五局三胜）。
Service fault
发球违例
抛球不够高（≥16cm）、合力发球（toss 时球在掌心转动）、遮挡发球等。
Edge ball
擦边球
球擦台面边缘——有效得分球。需举手示意「擦边，你的分」。
Net ball
擦网球
球擦网片后落入对方台面——正常比赛继续；发球时判 let 重发。
🏓动作 Actions
Loop / Forehand loop
弧圈球 / 正手拉球
强烈上旋攻击球——乒乓球核心技术。先打后摩（撞透海绵再摩擦）。
Drive
抽球/快攻
快速平击攻击球。中国快攻的招牌——近台快速、低弧、前冲。
Push / Backspin push
推球 / 搓球
搓球＝带下旋的推球。寸劲沿球底部斜砍即停——不前推（前推＝搓半高）。
Chop
削球
防守型下旋球——拍面仰起从下往上削。削球打法已边缘化。
Block / Backhand block
挡球 / 反手挡
零引拍防守——拍面迎前、上升期顶住，借力弹回。防弧圈的铁律：迎前不后缩。
Flip / Backhand flip
挑打 / 反手拧
台内进攻技术——架肘垂拍头、手腕从内屈向外展。反手拧拉（backhand flick）是现代乒乓球标志性技术。
Smash / Kill
杀球/扣杀
机会球的高压下杀。乒乓球杀球靠「先打后摩」——撞透海绵再加速收小臂。
Serve / Pendulum serve
发球 / 侧旋发球
钟摆式侧旋发球是主流——同抛球同引拍，只变触球部位与摩擦方向。转与不转一个动作。
Twiddle
转拍/倒板
长胶/生胶选手在回合中旋转球拍换面——正胶面攻、长胶面怪。已边缘化。
Punch / Punch block
弹击/快弹
反手小动作快速击球——肘为轴、小臂内收，是近台反手的核心攻击手段。
📍场地 Court
Table (2.74m × 1.525m)
球台（2.74m 长）
比任何球类场地都短——没有空间犯错，只有弧线能救你。
Net (15.25cm)
球网（高 15.25cm）
球网高度决定弧线——低网让快攻更容易，但也更容易下网。
Edge / Corner
台边 / 台角
擦边球（edge ball）＝有效球；台角是发球抢攻的目标落点。
🏸装备 Equipment
Blade（不是 Racket）
底板（乒乓球叫 Blade）
乒乓球的拍板叫 blade。五层纯木起步——碳素板容错低，动作定型后再上。
Rubber / Inverted / Pips
胶皮 / 反胶 / 颗粒胶
Inverted=反胶（光滑面）；Pips=颗粒胶（正胶/长胶/生胶）。反胶是绝对主流。
Tacky rubber / Chinese rubber
粘套 / 中国套（如狂飙）
硬质粘套需大动作鞭打＋长轨迹包裹；外套/涩套需迎前撞击＋短促寸劲。两套发力人格。
Sponge thickness / Hardness
海绵厚度 / 硬度
厚海绵弹性大容错低；硬度用度数表示（如 39°、40°）。新手选中等厚度＋中软硬度。
Boosting / Tuning
灌胶/膨胀
给海绵涂膨胀剂增加弹性——ITTF 2008 年起禁胶后属灰色地带。
♟️战术 Tactics
Third ball attack
第三板抢攻
发球→对方回球→第三板进攻——乒乓球最经典的得分模式。发球就是为第三板服务的。
Counter-loop
反拉/对拉
用弧圈球回击对方的弧圈球——中远台对拉是乒乓球最精彩的多拍场面。
Close-to-table
近台/快攻型
站在端线后半米以内、上升期击球——中国快攻的站位哲学。
Short / Drop short / Drop shot
摆短/回摆
接发球时把球轻摆到对方近网处不出台——借上升期触球即收，让对手无法抢拉。
Long push / Fast push
劈长
把球快速推到底线长球——迫使对方退台拉球，破坏近台快攻节奏。

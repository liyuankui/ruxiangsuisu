# 入乡随俗 RUXIANGSUISU · 拍类运动术语词典

> 入哪个球场，就说哪种球话。匹克球/羽毛球/乒乓球 中英术语对照。

🔗 https://liyuankui.github.io/ruxiangsuisu/

## Features

- **三运动五类术语**：呼报（Ball on!/Let/Fault）、动作（Dink/Loop/Clear）、场地（Kitchen/Tramlines/Edge）、装备（Paddle vs Racket vs Blade）、战术（Stacking/Third ball attack/Front-back rotation）
- **中英对照 + 场景用法**：每个术语附一句「什么时候用、怎么用」
- **实时搜索**：输入英文或中文即过滤（如搜 dink、厨房、Ball on）
- 网球篇制作中（tab 预留）
